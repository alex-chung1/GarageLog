# GarageLog

GarageLog is a vehicle maintenance tracking application that helps users manage vehicles and track service history.

## Tech Stack

### Backend

- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- ASP.NET Core Identity
- JWT Authentication
- Clean Architecture

### Frontend

- React
- React Router
- TypeScript
- Tailwind CSS
